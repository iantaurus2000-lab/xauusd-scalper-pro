# XAUUSD Scalper Pro V4.2

Signal-only Android app untuk XAU/USD.

## Fitur
- Data realtime dari **biquote.io** (gratis, tanpa API Key)
- Lampu Entry besar: 🟢 BUY / 🔴 SELL / ⚪ WAIT
- Chart M1 / M5 / M15
- EMA20 + EMA50
- Support & Resistance realtime
- Fibonacci 23.6 / 38.2 / 50 / 61.8 / 78.6
- Signal Wick-Tip + Liquidity Sweep + BOS
- Telegram alert
- Notification + Vibration

## Cara Build APK lewat HP (GitHub)

1. Extract file ZIP ini di HP
2. Buat repository baru di GitHub (Public)
3. Upload **semua file dan folder** yang ada di dalam ZIP
4. Buka tab **Actions**
5. Pilih workflow **"Build APK (Tanpa Keystore)"**
6. Klik **Run workflow** → tunggu 3-5 menit
7. Download artifact **XAUUSD-Scalper-V4.2-APK**
8. Install di HP

## Catatan
- Tidak perlu API Key market
- Tidak perlu setting secrets / keystore
- Cukup upload source code → build otomatis
