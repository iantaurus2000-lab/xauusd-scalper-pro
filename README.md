# XAUUSD Scalper Pro v5

Signal-only Android app (BUY LIMIT / SELL LIMIT).

## Fitur
- Session filter WITA (Asia / London / NY / Overlap)
- Multi-confluence: EMA + Sweep + Wick + BOS + RSI + Spread
- Entry sebagai **BUY LIMIT / SELL LIMIT**
- Chart geser horizontal & vertikal + pinch zoom
- Text berjalan (ticker session)
- Background service + notifikasi + getar
- Winrate / hasil entry

## Build APK (HP)
1. Buka tab **Actions**
2. Pilih **Build APK** → **Run workflow**
3. Tunggu hijau
4. Download artifact **XAUUSD-Scalper-Pro-APK**

## Catatan
- Auto entry = sinyal LIMIT (bukan order broker otomatis)
- Data gratis; fallback demo candle jika feed gagal
